# ask me about my mom

Site for the one-night exhibition of found footage and photographs, 1980 to 1990, shown at The Gangway Gallery on June 20.

Static HTML, no build step. Open `index.html` locally or serve it with GitHub Pages.

- `img/photos/` web photos: `name.jpg` is 2560 px on the long side (fullscreen viewer and hero), `name-sm.jpg` is 1280 px (grid)
- `img/footage/` placeholder stills for the video tiles until the real clips are in
